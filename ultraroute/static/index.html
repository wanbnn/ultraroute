Uma API, seis caminhos.

Conecte a sua ferramenta favorita usando o SDK da OpenAI.

Comece por aqui

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8989/v1",
    api_key="ur_SUA_CHAVE",
)

for chunk in client.chat.completions.create(
    model="chatgpt/web",
    messages=[{"role": "user", "content": "Olá!"}],
    stream=True,
):
    if chunk.choices:
        print(chunk.choices[0].delta.content or "", end="", flush=True)

Seu navegador, sua sessão

O UltraRoute detecta Chrome/Chromium nativo, Flatpak e Snap. Se não encontrar nenhum, instala Chromium via Flatpak de usuário (ou Snap, quando disponível). Os provedores compartilham o UltraProfile e usam abas separadas; duas contas do mesmo provedor recebem perfis distintos; você faz login antes de clicar em Já entrei · conectar. O controle só começa após essa confirmação.

A sessão e a autorização ficam salvas. Uma aba fechada é recriada; um navegador gerenciado encerrado é reaberto com o mesmo perfil na próxima chamada. Se a autenticação expirar, o painel solicitará novo login. Desconectar suspende a recuperação automática.

Conexão manual avançada

Para conectar um navegador que você já iniciou, use Conexão manual e informe a porta local. No Chromium Flatpak:

flatpak run org.chromium.Chromium \
  --remote-debugging-address=127.0.0.1 \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.var/app/org.chromium.Chromium/data/ultraroute/manual" \
  https://chat.deepseek.com/

Um navegador iniciado fora do UltraRoute pode ter suas abas recuperadas enquanto estiver aberto, mas não será relançado automaticamente. Use um perfil exclusivo para a conta.
